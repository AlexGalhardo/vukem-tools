# AGENTS.md

Vukem Tools: an open-source file conversion toolbox. Module
`github.com/AlexGalhardo/vukem-tools`. Backend entirely on the
[vukem](https://vukem.dev/docs/introduction) framework; frontend Inertia v3 + React with Base UI
and Tailwind CSS v4.

## Start here

1. Read [ROADMAP.md](ROADMAP.md): take the first unchecked task of the current phase. A task is
   done only when every child is checked **and** its quality asserts hold.
2. Read [docs/brainstorming.md](docs/brainstorming.md): the decisions and why. Decisions are final
   unless that file is updated first.
3. Read [docs/web-research.md](docs/web-research.md) before touching any conversion engine: its
   licence, its version and its traps are there.

## Commands

```bash
go build ./... && go vet ./... && golangci-lint run ./...
go test -race -count=1 ./...          # one package: ./internal/<pkg>/...
golangci-lint fmt ./...               # gofumpt + gci + golines, 120 cols, tabs
bun run typecheck && bun run build    # Inertia assets
bun run lint:md                       # markdownlint-cli2
go run ./cmd/app serve                # the app
go run ./cmd/app migrate              # migrations
```

## Rules

- Test first. A task is done only when its quality asserts in `ROADMAP.md` pass, and you show the
  command and its result.
- `net/http`-native through vukem; no globals, no `init()` registration, no reflection DI;
  `context.Context` first.
- **Stream, never buffer a whole file.** `io.Copy` to disk or object storage, `bufio` for generated
  output, shrink-on-load when decoding. This app must run on a small container.
- Bound concurrency explicitly, sized from the container's CPU quota, not the host's CPU count.
- Every engine runs as a subprocess with a timeout, a process-group kill and `setrlimit`
  ([`.claude/rules/engines.md`](.claude/rules/engines.md)). No cgo.
- Detect file types from magic bytes. Never trust the extension or the client's `Content-Type`.
- Secure by default, fail closed. Login is required for every tool; API keys carry abilities.
- Fix the root cause. Never silence an error, skip a test or add `//nolint` to make a check pass.
- Measure before claiming: `go test -bench . -benchmem`, recorded in `docs/benchmarks.md`.
- Commits: Conventional Commits, English, scope from [`.claude/rules/commits.md`](.claude/rules/commits.md).
- `CHANGELOG.md` is generated by git-cliff. Never hand-edit it; never move a pushed tag; push
  version tags one at a time.
- Everything — code, comments, docs, UI — in English. There is no i18n layer.
- Never edit the vukem repository from here. Framework problems go to
  `../framework-feedback/vukem-tools-feedback.md`
  ([`.claude/rules/framework-feedback.md`](.claude/rules/framework-feedback.md)).

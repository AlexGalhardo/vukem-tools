`vukem-tools mcp` is a Model Context Protocol server. It reads one JSON-RPC message per line on standard input, writes one per line on standard output, and opens no port. `tools/list` returns the 54 tools of the catalogue and `tools/call` runs the 37 that work on files, through the HTTP API of a Vukem Tools server.

Add it to Claude Code as a local server:

```bash
claude mcp add --env VUKEM_TOOLS_URL=http://localhost:3000 \
  --env VUKEM_TOOLS_API_KEY=vk_... \
  --transport stdio vukem-tools -- vukem-tools mcp
```

The command is the `vukem-tools` program from a release, see [Installation](/docs/installation#the-command-line-program). Setups for Claude Desktop and Cursor, the protocol and every tool's arguments are in the [MCP section](/docs/mcp/overview).

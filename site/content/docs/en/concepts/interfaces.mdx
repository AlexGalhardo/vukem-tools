---
title: "One catalogue, four doors"
description: "The browser, the desktop window, the CLI, HTTP, and MCP call the same tools."
---

| Door | How you open a tool |
| --- | --- |
| Browser | `/tools/<name>` after you sign in |
| Desktop | The window loads `VUKEM_TOOLS_URL` plus `/tools/<name>` |
| CLI | `vukem-tools tools`, then `vukem-tools pdf crop` |
| HTTP | `POST /api/v1/tools/pdf-crop` with an API key |
| MCP | `vukem-tools mcp`, then `tools/call` of `pdf-crop` |

`vukem-tools serve` listens on `127.0.0.1:8787` by default and answers `GET /tools` and `POST /pdf/crop` for a local agent. That port is the agent server. The web app listens on port 3000.

The release you are running is printed at the bottom left of the web app and of the desktop window.

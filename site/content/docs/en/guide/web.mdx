The web app is the interface of the server. After you sign in, the sidebar lists the tools in groups, and `Ctrl+K` searches them. Each tool is a page at `/tools/<name>`: choose a file, set the options, run it, and download the result.

## Accounts

Every tool needs an account. You can sign in with an email and a password. A server can also offer Google sign-in. Open **Account** to change your profile and password, to create and revoke [API keys](/docs/api/overview#authentication), and to approve a [device link](/docs/api/overview#link-a-program-without-a-password) for a program such as the Telegram bot.

## What happens to your file

1. The file is uploaded to the server. Its type is read from its bytes. A server may scan uploads for malware.
2. A worker runs the tool in an engine, as a separate process with a time limit. You see the progress on the page.
3. The result is stored, not held in memory. You have five minutes to download it, then it is deleted.

An upload that no conversion used is deleted after 30 minutes. An operator can change both times.

## Tools that run in the page

The developer tools, the LLM tools and the Brazil tools run in your browser. See the [catalogue](/docs/concepts/catalogue).

## Health checks

`GET /health` answers when the server is alive. `GET /health/deep` also checks its dependencies, hides versions from anonymous callers and is rate limited.

## This documentation

This site is static and lives at `https://tools.vukem.dev`. The app is a different program: it runs on your machine or your server, and the sidebar link **Documentation** opens this site.

---
title: "CLI reference"
description: "Commands of vukem-tools and the JSON they print."
---

| Command | Result |
| --- | --- |
| `vukem-tools tools` | `{"tools":[...]}` on stdout |
| `vukem-tools pdf crop --input f --output f` | `{"output","cropped","bytes"}` |
| `vukem-tools mcp` | JSON-RPC on stdin and stdout |
| `vukem-tools serve` | HTTP on `127.0.0.1:8787` |

An unknown command, or a crop without `--input` and `--output`, writes `{"error":"..."}` to stderr and exits with status 2. A crop that fails in qpdf exits with status 1.

There is no `version` subcommand. The release is the version in `package.json`, the GitHub tag, and the label at the bottom left of the app.

title: "Licences"
description: "The app is MIT. Several engines are not, and the licences page lists them."
---

The application code is MIT. Conversion engines run as separate programs and keep their own licences. GPL and AGPL engines are declared on the `/licenses` page of the web app before a feature that uses them ships.

The exact versions and the traps of each engine are in `docs/web-research.md` in the repository. The Docker image pins those versions. Do not swap in a distro package or a `latest` tag.

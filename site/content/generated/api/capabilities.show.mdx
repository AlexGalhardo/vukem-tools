## Authentication

Send your API key as `Authorization: Bearer <key>`. The `X-API-Key` header works too, and `Authorization` wins when both are present. Any valid key works: no ability is needed.

## Responses

### 200 OK

Content type `application/json`. Schema: [`CapabilitiesView`](/docs/api/schemas#capabilitiesview).

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `engines` | array of [`EngineView`](/docs/api/schemas#engineview) | - | Every external program, and whether this server has it |
| `limits` | [`LimitsView`](/docs/api/schemas#limitsview) | - | The numbers this server enforces |
| `tools` | array of `string` | - | Every tool that can be submitted |

### 401 Unauthorized

Content type `application/problem+json`. Error (RFC 9457 problem details). Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

### Any other status

Content type `application/problem+json`. Error (RFC 9457 problem details). Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

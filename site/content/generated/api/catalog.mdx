Ask the server what it can do before you call it: tools, file types, formats, engines and limits. Every example reads the server from `VUKEM_TOOLS_URL` and the key from `VUKEM_TOOLS_API_KEY`; see [the overview](/docs/api/overview) for how to set them.

## GET /api/v1/capabilities

**Report which engines this server has and what its limits are.**

Every external program, whether it was resolved at startup and the version it reported, plus the registered tools and the numbers this server enforces. An engine the image does not carry hides its tools, and this is where that is visible.

| Property | Value |
| --- | --- |
| Auth | API key (`Authorization: Bearer` or `X-API-Key`) |
| Ability | Any valid key. No ability is needed. |

**Example**

```bash
curl -sS "$VUKEM_TOOLS_URL/api/v1/capabilities" \
  -H "Authorization: Bearer $VUKEM_TOOLS_API_KEY"
```

**Responses**

| Status | Meaning | Body |
| --- | --- | --- |
| 200 | OK | `CapabilitiesView` |
| 401 | An error, as a problem document | [Problem](/docs/api/errors) |
| Other | An error, as a problem document | [Problem](/docs/api/errors) |

Example of a success body:

```json
{
  "engines": [
    {
      "name": "yt-dlp",
      "present": true,
      "version": "2026.08.19"
    },
    {
      "name": "ffmpeg",
      "present": true,
      "version": "ffmpeg version 7.1.5-0+deb13u1 Copyright (c) 2000-2026 the FFmpeg developers"
    },
    {
      "name": "ffprobe",
      "present": true,
      "version": "ffprobe version 7.1.5-0+deb13u1 Copyright (c) 2007-2026 the FFmpeg developers"
    },
    {
      "name": "gs",
      "present": true,
      "version": "10.05.1"
    }
  ],
  "limits": {
    "max_clip_seconds": 60,
    "max_clips": 60,
    "max_download_bytes": 524288000,
    "max_output_seconds": 1800
  },
  "tools": [
    "pixels-to-svg",
    "video-clip",
    "video-compress",
    "video-download"
  ]
}
```

The API has 63 routes under `/api/v1`. This table is the index; each row links to the section that has the parameters, the body, a `curl` example and the responses. "Needs" is the ability a key must carry: `public` means no key, `any key` means any valid key.

Two more routes sit outside `/api/v1` because they do not speak JSON: the resumable upload at `/uploads/tus/` and the signed download at `/files/{id}`. Both are in [Convert a file](/docs/api/workflow).

Pack and unpack archives, split and build sprite sheets, and turn pixel art into SVG. Every example reads the server from `VUKEM_TOOLS_URL` and the key from `VUKEM_TOOLS_API_KEY`; see [the overview](/docs/api/overview) for how to set them.

## POST /api/v1/tools/archive-create

**Pack several files into one archive.**

ZIP, TAR.GZ, TAR or GZ. The order of file_ids is the order of the entries, and each entry keeps the name its upload had. gz is the exception: it compresses a single stream, so submitting more than one file for it is a validation error rather than an archive holding only the first. XZ and ZSTD are not offered — neither is in the Go standard library, and the four formats here cover what a web service is sent.

| Property | Value |
| --- | --- |
| Auth | API key (`Authorization: Bearer` or `X-API-Key`) |
| Ability | `archive:files` |

**Request body** (`application/json`)

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `file_ids` | array of string | yes | The uploads to pack, in order. One to sixty-four. at least 1 items; at most 64 items |
| `idempotency_key` | string | no | Repeat a submission safely: the same key returns the same conversion. max length 128 |
| `options` | object | no | The format, the compression level and the archive's name. Every field is optional. |
| `options.format` | string | no | Zip, tar.gz, tar or gz. Default zip. max length 8 |
| `options.level` | integer | no | Compression level, 1 to 9. 0 uses the format's default. min 0; max 9 |
| `options.name` | string | no | The archive's name, without an extension. Default archive. max length 64 |

**Example**

```bash
curl -sS -X POST "$VUKEM_TOOLS_URL/api/v1/tools/archive-create" \
  -H "Authorization: Bearer $VUKEM_TOOLS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "file_ids": [
    "01JQ8Z5X0K7M3N9P2R4T6V8W0Y",
    "01JQ8Z6A1M8N4P0R3T5V7X9Z1B"
  ],
  "idempotency_key": "release-assets-v2",
  "options": {
    "format": "zip",
    "level": 6,
    "name": "release-assets"
  }
}'
```

## POST /api/v1/tools/archive-extract

**Unpack an archive into its files.**

Each member becomes a result of its own with its own expiry, so all of them have to be downloaded within the result lifetime. The format is read from the archive's bytes rather than its name. Folders are flattened: only a member's filename survives, and two members that then share a name are both kept, numbered. An archive is refused if it holds more than 64 files or unpacks to more than 512 MB, or if any member is a link or a device rather than a file.

| Property | Value |
| --- | --- |
| Auth | API key (`Authorization: Bearer` or `X-API-Key`) |
| Ability | `archive:files` |

**Request body** (`application/json`)

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `file_id` | string | yes | The id of an upload of yours: a ZIP, TAR, TAR.GZ or GZ. min length 1 |
| `idempotency_key` | string | no | Repeat a submission safely. max length 128 |
| `options` | object | no | Extracting has no options: the archive says what it is. |

**Example**

```bash
curl -sS -X POST "$VUKEM_TOOLS_URL/api/v1/tools/archive-extract" \
  -H "Authorization: Bearer $VUKEM_TOOLS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
  "file_id": "01JQ8Z5X0K7M3N9P2R4T6V8W0Y",

}'
```

## POST /api/v1/tools/pixels-to-svg

**Turn pixel art into SVG.**

Traces an uploaded image into SVG. The upload and the conversion are bound in one transaction, so a conversion always has its input. Send an idempotency_key to make a retry safe.

| Property | Value |
| --- | --- |
| Auth | API key (`Authorization: Bearer` or `X-API-Key`) |
| Ability | `pixels:svg` |

**Request body** (`application/json`)

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `file_id` | string | yes | The id of an upload of yours, from the resumable upload endpoint. min length 1 |
| `idempotency_key` | string | no | Repeat a submission safely: the same key returns the same conversion. max length 128 |
| `options` | object | no | How to convert. Every field is optional. |
| `options.alpha` | string | no | Opacity keeps partial transparency, drop removes it. Default opacity. max length 16 |
| `options.max_colors` | integer | no | Palette cap, 1 to 256. 0 uses the default, -1 means no reduction. min -1; max 256 |
| `options.mode` | string | no | Square, rect or contour. Default rect. max length 16 |
| `options.scale` | integer | no | Multiplies the rendered size. 0 and 1 both mean actual size. min 0; max 64 |
| `options.simplify` | number | no | Contour simplification in pixels, contour mode only. 0 keeps it pixel-exact. min 0; max 16 |
| `options.tolerance` | integer | no | Merge colours closer than this (0 to 255). 0 disables merging. min 0; max 255 |

## POST /api/v1/tools/sprite-build

**Pack frames into a sprite sheet.**

Takes a ZIP of frames. The grid layout gives every frame an identical cell and is the default, because it is what Godot 4 and Unity import with no metadata file at all; compact packs frames of differing sizes more tightly. Frames that do not fit are refused with the count that fitted and the size that would be needed, never silently dropped. The packer never rotates a frame.

| Property | Value |
| --- | --- |
| Auth | API key (`Authorization: Bearer` or `X-API-Key`) |
| Ability | `sprite:sheet` |

**Request body** (`application/json`)

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `file_id` | string | yes | The id of an upload of yours: a ZIP of frames. min length 1 |
| `idempotency_key` | string | no | Repeat a submission safely. max length 128 |
| `options` | object | no | How to pack the frames, and which metadata to write. |
| `options.aseprite` | boolean | no | Add Aseprite's per-frame duration and frameTags to the JSON formats. |
| `options.extrude` | integer | no | Repeat each frame's edge pixels into the padding, which is the fix for the dark halo transparent padding leaves. min 0; max 8 |
| `options.frame_ms` | integer | no | Per-frame duration in milliseconds for the Aseprite extensions. 0 means 100. min 0; max 60000 |
| `options.layout` | string | no | Grid or compact. Default grid, which Godot 4 and Unity import with no metadata file. max length 8 |
| `options.margin` | integer | no | Transparent gutter at the sheet's edges. min 0; max 256 |
| `options.max_size` | integer | no | Cap the sheet's width and height. 0 means 4096, which every GPU handles as one texture. min 0; max 8192 |
| `options.metadata` | array of string | no | Metadata formats to write, at most four. at most 4 items |
| `options.padding` | integer | no | Transparent gutter between two frames, which stops a neighbour's colour bleeding in. min 0; max 256 |
| `options.pot` | boolean | no | Round the sheet up to a power of two on both axes. |

## POST /api/v1/tools/sprite-split

**Cut a sprite sheet into frames.**

Grid mode cuts the sheet on a grid you describe and is exact; auto mode finds each frame's bounding box from the sheet's own content, which is the answer for a hand-drawn sheet. A fully opaque sheet with no background colour named is refused rather than guessed at. The result is one archive — the frames and the metadata together, so one download is self-contained — plus each metadata file on its own. Trimming is refused with the css format, which has nowhere to record the offset.

| Property | Value |
| --- | --- |
| Auth | API key (`Authorization: Bearer` or `X-API-Key`) |
| Ability | `sprite:sheet` |

**Request body** (`application/json`)

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `file_id` | string | yes | The id of an upload of yours: the sheet to cut. min length 1 |
| `idempotency_key` | string | no | Repeat a submission safely: the same key returns the same conversion. max length 128 |
| `options` | object | no | How to find the frames, and which metadata to write. |
| `options.aseprite` | boolean | no | Add Aseprite's per-frame duration and frameTags to the JSON formats. |
| `options.background` | string | no | Hex colour auto mode treats as empty, e.g. #ff00ff. Empty means transparency. max length 9 |
| `options.background_tolerance` | integer | no | How far a pixel may be from the background colour and still count as background. min 0; max 255 |
| `options.cell_h` | integer | no | Cell height in pixels. min 0; max 8192 |
| `options.cell_w` | integer | no | Cell width in pixels. Give this and cell_h, or cols and rows. min 0; max 8192 |
| `options.cols` | integer | no | Column count, as an alternative to the cell size. min 0; max 2048 |
| `options.frame_ms` | integer | no | Per-frame duration in milliseconds for the Aseprite extensions. 0 means 100. min 0; max 60000 |
| `options.margin` | integer | no | Gutter between the sheet's edge and the first cell. min 0; max 256 |
| `options.metadata` | array of string | no | Metadata formats to write, at most four. GET /api/v1/tools/sprite-split/formats lists them. at most 4 items |
| `options.min_frame` | integer | no | Drop a detected frame smaller than this many pixels, as noise. Auto mode only. min 0; max 1000000 |
| `options.mode` | string | no | Grid or auto. Default grid. max length 8 |
| `options.prefix` | string | no | Frame name prefix; the nth frame is prefix plus a zero-padded index. Default frame. max length 64 |
| `options.rows` | integer | no | Row count. min 0; max 2048 |
| `options.spacing` | integer | no | Gutter between two neighbouring cells. min 0; max 256 |
| `options.trim` | boolean | no | Shrink each frame to its opaque box, recording the offset so an importer can re-inflate it. Refused with the css metadata format, which has nowhere to put the offset. |

```bash
  "idempotency_key": "hero-walk-cycle",
  "options": {
    "aseprite": true,

    "margin": 0,
```

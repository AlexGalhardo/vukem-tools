## POST /api/v1/tools/audio-convert

**Convert audio, or extract a video's soundtrack.**

The same operation either way: a video input has its picture dropped and its audio encoded. Loudness normalisation aims at -16 LUFS, the figure streaming platforms use, and the two-pass form measures the whole recording first so it actually hits the target.

| Property | Value |
| --- | --- |
| Auth | API key (`Authorization: Bearer` or `X-API-Key`) |
| Ability | `audio:convert` |

**Request body** (`application/json`)

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `file_id` | string | yes | The id of an upload of yours, from the resumable upload endpoint. min length 1 |
| `idempotency_key` | string | no | Repeat a submission safely: the same key returns the same conversion. max length 128 |
| `options` | object | no | How to convert. Only the output format is required. A video input has its soundtrack extracted. |
| `options.bitrate` | integer | no | Bit rate in kbit/s for MP3, Opus and AAC. 0 uses the format's default. Ignored by FLAC and WAV, which are lossless. min 0; max 320 |
| `options.channels` | integer | no | 1 for mono, 2 for stereo. 0 keeps the source's. min 0; max 2 |
| `options.normalise` | boolean | no | Normalise the loudness to -16 LUFS, the figure streaming platforms use. |
| `options.sample_rate` | integer | no | Resample, in hertz. 0 keeps the source's rate. min 0; max 192000 |

| `options.two_pass` | boolean | no | Measure the whole recording before correcting it. Costs a second decode and is the only way to hit the target reliably. |

## POST /api/v1/tools/image-compress

**Make an image smaller without changing what it is.**

The format never changes; image-convert is what changes a format. Each mode runs every encoder setting worth trying and keeps the smallest file, so a lossy compression can legitimately come back lossless when that was smaller. A file this encoder cannot beat is returned unchanged with the fact stated, rather than re-encoded into something larger. PNG and GIF compress losslessly by default, JPEG and WebP lossily; lossless is refused for JPEG, because libvips has no lossless JPEG re-encode and jpegtran is not in this image. Metadata is always removed.

## POST /api/v1/tools/video-clip

## Authentication

No key is needed: the account's email and password are the credential, and the account's email must be verified. The key you get carries only the abilities you ask for. This route is limited to 5 calls a minute per address. See [Authentication](/docs/api/overview#authentication).

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `abilities` | array of `string` | yes | What the key may do; GET /api/v1/abilities lists the accepted values. at least 1 items; at most 16 items |
| `code` | `string` | no | A two-factor code, for accounts with two-factor authentication. max length 16 |
| `device_name` | `string` | yes | A label for this key, shown when listing keys. min length 1; max length 100 |
| `email` | `string (email)` | yes | The account's email address. min length 1 |
| `password` | `string` | yes | The account's password. min length 1 |
| `recovery_code` | `string` | no | A two-factor recovery code, instead of code. max length 32 |

## Responses

### 201 Created

Content type `application/json`. Schema: [`TokenIssued`](/docs/api/schemas#tokenissued).

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `abilities` | array of `string` | - | What this key may do |
| `expires_at` | `string (date-time)` or `null` | - | When the key stops working, or null when it never expires |
| `id` | `string` | - | The key id, used to revoke it |
| `token` | `string` | - | The secret key. It is shown once; store it now |
| `type` | `string` | - | The authorization scheme to use, always "Bearer" |

### 422 Unprocessable Content

Content type `application/problem+json`. Validation failed; errors maps each field to its messages and issues lists each problem with its code, key and params. Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

### Any other status

Content type `application/problem+json`. Error (RFC 9457 problem details). Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

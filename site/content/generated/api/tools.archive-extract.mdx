The format is read from the archive's bytes rather than its name. Folders are flattened: only a member's filename survives, and two members that then share a name are both kept, numbered. ## Authentication

Send your API key as `Authorization: Bearer <key>`. The `X-API-Key` header works too, and `Authorization` wins when both are present. The key needs the `archive:files` ability.

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `file_id` | `string` | yes | The id of an upload of yours: a ZIP, TAR, TAR.GZ or GZ. min length 1 |
| `idempotency_key` | `string` | no | Repeat a submission safely. max length 128 |
| `options` | [`ArchiveExtractOptions`](/docs/api/schemas#archiveextractoptions) | no | Extracting has no options: the archive says what it is |

## Responses

### 201 Created

Content type `application/json`. Schema: [`ConversionView`](/docs/api/schemas#conversionview).

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `bytes_in` | `integer (int64)` | - | Size of the input in bytes |
| `bytes_out` | `integer (int64)` | - | Size of the result in bytes, 0 until it finishes |
| `created_at` | `string (date-time)` | - | When it was submitted |
| `error_message` | `string` | - | What to tell the user, empty unless it failed |
| `error_type` | `string` | - | A code from the error taxonomy, empty unless it failed |
| `expires_at` | `string (date-time)` | - | When the result stops being downloadable |
| `finished_at` | `string (date-time)` or `null` | - | When it ended, or null |
| `id` | `string` | - | The conversion id, used to poll it, stream it or cancel it |
| `note` | `string` | - | What the conversion did, in its own words. Empty when the file says it all |
| `phase` | `string` | - | What it is doing now, empty once it has ended |
| `progress` | `integer` | - | Percentage from 0 to 100 |
| `started_at` | `string (date-time)` or `null` | - | When a worker picked it up, or null |
| `status` | `string` | - | One of pending, running, finished, error, cancelled |
| `tool` | `string` | - | Which conversion produced it |

### 401 Unauthorized

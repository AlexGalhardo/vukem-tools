## Authentication

No key is needed. This route is public.

## Responses

### 200 OK

Content type `application/json`. Schema: [`AudioCapabilities`](/docs/api/schemas#audiocapabilities).

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `formats` | array of [`AudioFormat`](/docs/api/schemas#audioformat) | - | Every output format, with whether this server can write it |
| `loudness_target` | `number (double)` | - | The integrated loudness normalisation aims at, in LUFS |
| `max_seconds` | `number (double)` | - | The longest recording this server converts, in seconds |
| `readable` | array of `string` | - | The media types this server accepts, including video, since extracting a soundtrack is the same conversion |
| `sample_rates` | array of `integer` | - | The sample rates a conversion may ask for. 0 keeps the source's |
| `writable` | array of `string` | - | The formats this server can write, by name |

### Any other status

Content type `application/problem+json`. Error (RFC 9457 problem details). Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

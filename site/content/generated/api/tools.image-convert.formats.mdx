## Authentication

No key is needed. This route is public.

## Responses

### 200 OK

Content type `application/json`. Schema: [`MediaCapabilities`](/docs/api/schemas#mediacapabilities).

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `flips` | array of `string` | - | Horizontal or vertical |
| `formats` | array of [`ImageFormat`](/docs/api/schemas#imageformat) | - | Every image format, with whether this server can read it, write it, or both |
| `readable` | array of `string` | - | The media types this server accepts as input |
| `resize_modes` | array of `string` | - | Fit, fill or exact |
| `rotations` | array of `integer` | - | The quarter turns a client may ask for |
| `writable` | array of `string` | - | The formats this server can write, by name |

### Any other status

Content type `application/problem+json`. Error (RFC 9457 problem details). Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

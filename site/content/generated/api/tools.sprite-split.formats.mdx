## Authentication

No key is needed. This route is public.

## Responses

### 200 OK

Content type `application/json`. Schema: [`SpriteCapabilities`](/docs/api/schemas#spritecapabilities).

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `formats` | array of [`SpriteFormat`](/docs/api/schemas#spriteformat) | - | Every metadata format, in the order the interface offers them |
| `layouts` | array of `string` | - | How sprite-build arranges them |
| `max_formats` | `integer` | - | How many metadata formats one conversion may ask for |
| `max_frames` | `integer` | - | The most frames one conversion produces |
| `max_size` | `integer` | - | The largest sheet dimension, in pixels |
| `modes` | array of `string` | - | How sprite-split finds frames |

### Any other status

Content type `application/problem+json`. Error (RFC 9457 problem details). Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

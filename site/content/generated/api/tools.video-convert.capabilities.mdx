## Authentication

No key is needed. This route is public.

## Responses

### 200 OK

Content type `application/json`. Schema: [`VideoCapabilities`](/docs/api/schemas#videocapabilities).

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `codecs` | array of `string` | - | The video codecs this server can encode. An ffmpeg built without GPL support has no H.264 or H.265 |
| `containers` | array of [`VideoContainer`](/docs/api/schemas#videocontainer) | - | Every output container, with the codecs it carries |
| `dithers` | array of `string` | - | The dithering modes video-to-gif accepts |
| `gpl_build` | `boolean` | - | Whether the video engine is built with GPL support, which H.264 and H.265 require |
| `max_gif_seconds` | `number (double)` | - | The longest range video-to-gif will convert, in seconds |
| `max_seconds` | `number (double)` | - | The longest video this server converts, in seconds |

### Any other status

Content type `application/problem+json`. Error (RFC 9457 problem details). Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

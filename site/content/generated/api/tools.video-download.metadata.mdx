## Authentication

Send your API key as `Authorization: Bearer <key>`. The `X-API-Key` header works too, and `Authorization` wins when both are present. The key needs the `video:download` ability.

## Request body

Content type `application/json`.

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `url` | `string` | yes | A YouTube, Instagram, X or TikTok URL. min length 1; max length 2048 |

## Responses

### 200 OK

Content type `application/json`. Schema: [`MediaView`](/docs/api/schemas#mediaview).

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `duration_seconds` | `number (double)` | - | How long it is |
| `estimated_bytes` | `integer (int64)` | - | The expected size at best quality. The cap is checked against this for quality=best |
| `formats` | array of [`MediaFormat`](/docs/api/schemas#mediaformat) | - | Every stream the platform offers |
| `max_bytes` | `integer (int64)` | - | The largest download this server allows |
| `platform` | `string` | - | Youtube, instagram, x or tiktok |
| `smallest_bytes` | `integer (int64)` | - | The expected size at quality=smallest, 0 when the platform declares none |
| `thumbnail` | `string` | - | A link to the platform's own thumbnail |
| `title` | `string` | - | The video's title, as the platform gives it |
| `too_large` | `boolean` | - | Whether even the smallest stream is past the cap |
| `uploader` | `string` | - | Who posted it |

### 401 Unauthorized

Content type `application/problem+json`. Error (RFC 9457 problem details). Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

### 422 Unprocessable Content

Content type `application/problem+json`. Validation failed; errors maps each field to its messages and issues lists each problem with its code, key and params. Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

### Any other status

Content type `application/problem+json`. Error (RFC 9457 problem details). Schema: [`Problem`](/docs/api/schemas#problem).

The error follows RFC 9457. See [Errors](/docs/api/overview#errors).

These 6 tools run on the server. Over MCP each is a `tools/call` with the arguments below; on the command line each is the `vukem-tools` command shown. Every tool reads its files from paths on your machine and writes the result to `output`.

## audio-convert

**Convert audio.** Between MP3, WAV, FLAC, Ogg and AAC, with the bitrate under your control.

The same operation either way: a video input has its picture dropped and its audio encoded. Loudness normalisation aims at -16 LUFS, the figure streaming platforms use, and the two-pass form measures the whole recording first so it actually hits the target.

| Property | Value |
| --- | --- |
| Ability | `audio:convert` |
| CLI | `vukem-tools audio convert` |
| API route | `POST /api/v1/tools/audio-convert` |

**Arguments**

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `input` | string | yes | Path of the file to read. |
| `output` | string | yes | Where to write the result: a file path, or a directory for a tool that yields several files. |
| `options` | object | no | How to convert. Only the output format is required. A video input has its soundtrack extracted. |
| `idempotency_key` | string | no | Repeat a call safely: the same key returns the same conversion. |

**Options**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `options.bitrate` | integer | no | Bit rate in kbit/s for MP3, Opus and AAC. 0 uses the format's default. Ignored by FLAC and WAV, which are lossless. min 0; max 320 |
| `options.channels` | integer | no | 1 for mono, 2 for stereo. 0 keeps the source's. min 0; max 2 |
| `options.normalise` | boolean | no | Normalise the loudness to -16 LUFS, the figure streaming platforms use. |
| `options.sample_rate` | integer | no | Resample, in hertz. 0 keeps the source's rate. min 0; max 192000 |
| `options.to` | string | no | Mp3, wav, flac, opus or aac. GET /api/v1/tools/audio-convert/formats lists what this server can write. max length 8 |
| `options.two_pass` | boolean | no | Measure the whole recording before correcting it. Costs a second decode and is the only way to hit the target reliably. |

**Example**

```json
{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"audio-convert","arguments":{"input":"in.file","output":"out.file"}}}
```

## video-clip

**Cut and crop a video.** Trims to a range, crops the frame, or splits a long recording into clips of up to a minute. Cuts on a keyframe without re-encoding unless you ask for an exact cut.

Trims an uploaded video to a range, crops the frame, or splits it into consecutive clips of up to a minute. A cut that lands on a keyframe is copied rather than re-encoded, which is an order of magnitude cheaper; frame_accurate forces the re-encode. A crop is validated against the real stream dimensions, and a crop outside them is refused with those dimensions named.

## video-compress

**Compress a video or audio file.** Makes a video or an audio file smaller and reports exactly how much was saved. When it cannot be improved you get the original back, unchanged, and it says so.

Re-encodes an uploaded file and returns whichever is smaller, the result or the original. When the original wins, the conversion still finishes: bytes_out equals bytes_in and the result is the file you sent, which is the honest answer for something that is already optimal.

## video-convert

**Convert a video.** Between MP4, WebM and MKV, with the codec and the resolution under your control.

Progress is reported on the conversion's event stream. A codec the container cannot carry usefully, or that this build cannot encode, is refused here rather than by the engine a minute later.

| Property | Value |
| --- | --- |
| Ability | `video:convert` |
| CLI | `vukem-tools video convert` |
| API route | `POST /api/v1/tools/video-convert` |

**Arguments**

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `input` | string | yes | Path of the file to read. |
| `output` | string | yes | Where to write the result: a file path, or a directory for a tool that yields several files. |
| `options` | object | no | How to convert. Only the container is required; the codecs default to the ones that container plays everywhere. |
| `idempotency_key` | string | no | Repeat a call safely: the same key returns the same conversion. |

**Options**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `options.audio` | string | no | Aac, opus, mp3, flac, vorbis, copy or mute. Empty uses the container's default. max length 8 |

| `options.container` | string | no | Mp4, webm, mkv or mov. max length 8 |

## video-download

**Download a video.** Fetches a video from YouTube, Instagram, X or TikTok at the quality you pick, keeps the audio only if you prefer, and can split it into short clips.

Fetches a video from YouTube, Instagram, X or TikTok. This is the one conversion with no upload: the input is the URL, so bytes_in is 0 until the download has happened. Ask for audio to get MP3, for clips to get consecutive segments delivered individually and as a zip, and for compression to have the result re-encoded and whichever file is smaller delivered. Downloading may breach a platform's terms of service and you are responsible for what you download.

## video-to-gif

**Video to GIF.** Turns a few seconds of a video into an animated GIF, with a palette computed from the clip itself rather than a fixed one.

Two passes: a palette is computed from the frames in the clip and the frames are then mapped onto it, which is the difference between a GIF that looks like the video and one that bands. Capped at 15 seconds, because a GIF's size grows linearly with its duration.

| Property | Value |
| --- | --- |
| Ability | `video:convert` |
| CLI | `vukem-tools video to-gif` |
| API route | `POST /api/v1/tools/video-to-gif` |

**Arguments**

| Argument | Type | Required | Notes |
| --- | --- | --- | --- |
| `input` | string | yes | Path of the file to read. |
| `output` | string | yes | Where to write the result: a file path, or a directory for a tool that yields several files. |
| `options` | object | no | Which part of the video, and how. Every field is optional. |
| `idempotency_key` | string | no | Repeat a call safely: the same key returns the same conversion. |

**Options**

| Field | Type | Required | Notes |
| --- | --- | --- | --- |
| `options.dither` | string | no | Dithering mode. Empty uses sierra2_4a. max length 20 |
| `options.duration_seconds` | number | no | How long, in seconds. 0 takes the rest of the video, up to the 15 second limit. min 0 |
| `options.fps` | integer | no | Frames per second. 0 uses 12, which divides 100 evenly and so plays evenly. min 0; max 50 |
| `options.start_seconds` | number | no | Where to start, in seconds. min 0 |
| `options.width` | integer | no | Width in pixels. 0 uses 480: a GIF has no interframe compression, so doubling the width quadruples the file. min 0; max 1920 |

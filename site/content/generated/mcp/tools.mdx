`tools/list` returns 54 tools. 37 of them run on the server and can be called over MCP or from the command line; each has its own page below. The other 17 run in the browser on the site: they appear in `tools/list` so an agent knows they exist, but `tools/call` answers `browser_only`.

The list is read from `internal/toolkit/tools.json`, the same table the CLI uses, and a test keeps it equal to the catalogue and to the OpenAPI document.

## Arguments every tool shares

| Argument | Notes |
| --- | --- |
| `input` | Path of the file to read, for a tool that takes one file. |
| `inputs` | Paths of the files to read, for a tool that takes several. |
| `output` | Where to write the result. A file path, or a directory for a tool that yields several files. Required. |
| `options` | An object with the tool's own options. Required for some tools, as each page says. |
| `idempotency_key` | Up to 128 characters. The same key returns the same conversion. |
